# UMP Protocol Debugger

Command-line utility for debugging and tracing UMP protocol traffic.

## Features

- Inspect UMP packets
- Trace packet flow
- Display packet metadata
- Record protocol events
- Filter trace output
- Export traces as JSON
- Log protocol activity

## Usage

```text
python debugger.py packet.json
python debugger.py packet.json --trace
python debugger.py packet.json --json
python debugger.py packet.json --verbose
